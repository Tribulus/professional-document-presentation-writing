# Professional Document & Presentation Writing Skill

用于规划、撰写、修改和核查课程论文、研究报告、商业分析、产品与运营文档及演示文稿。

## 安装与调用

下载完整仓库，将解压后的文件夹命名为 `professional-document-presentation-writing`，放入个人 Skill 目录。常用位置为 `~/.codex/skills/`，Windows 上对应 `%USERPROFILE%\.codex\skills\`。保留 `SKILL.md`、`references/` 和 `agents/` 的相对位置。

可以直接描述任务，也可以在请求开头加上 `$professional-document-presentation-writing`。附上任务要求、稿件、参考资料或模板，有助于沿用项目约束。

## 使用示例

- 阅读这份课程要求，给我三个可行的研究方向，分别说明证据需求和取舍。
- 按已确认的大纲写报告，逐条核查数据与引用，并标出图表制作要求。
- 把报告做成 12 分钟的课堂展示。先给逐页大纲、密度选择和建议时长，确认后再制作。
- 精简第 6 页，保留关键证据，并同步更新演讲者备注和建议时长。

方向未定时，Skill 先读材料，再提供有明确证据需求和取舍的选项。要求明确时可直接执行。文档默认提供图表占位和制作说明。PPT 支持逐页规划、可编辑图表和结构图、渲染复检及原生 Speaker Notes，具体交付能力取决于所用工具。
